# Oficjalne materiały organizatora

Sprawdzono 3 listopada 2026 na [stronie konkursu UwB](https://informatyka.uwb.edu.pl/popularyzacja2/sztuczna-inteligencja-wsrod-nas). Odczytano stronę i treść regulaminu oraz załączników PDF przez narzędzie web. Próba pobrania lokalnych kopii przez HTTP zakończyła się 403, dlatego w tym folderze nie ma plików udających pobrane oryginały. Pobierz je ręcznie z sekcji „Pliki do pobrania” na stronie organizatora.

Strona oraz regulamin wskazują termin kompletnego zgłoszenia 29 listopada 2026. Pakiet obejmuje formularze, źródła i instrukcję kompilacji, aplikację binarną z instrukcją uruchomienia, instrukcję użytkownika, film AVI/MP4 do 5 minut oraz opis do jednej strony. Źródłem tych ustaleń jest §3 ust.7 regulaminu dostępnego na oficjalnej stronie. Adresy źródeł i status odczytu zapisano w checks/contest-sources.json.

Załączniki zawierają kartę zgłoszenia, klauzulę informacyjną i kwestionariusz dla laureatów. Wypełnienie i podpisy pozostają po stronie autora; kwestionariusz laureata nie jest formularzem bieżącego zgłoszenia. Przed wysłaniem sprawdź warunki uczestnictwa oraz aktualność plików u organizatora. Nie ustalono indywidualnej kwalifikacji autora i nie wysłano zgłoszenia.
